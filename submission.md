## Description

Reletter helps teams discover and research millions of newsletters. Use this integration to search by topic, title or author, filter results, retrieve individual newsletter details and check API usage. The node works in ordinary workflows and as an AI Agent tool, with simplified, raw or selected output fields. Each customer connects their own API key from an account with API access.
